# QA Report Local Agent

Локальный агент обращается к Jira с компьютера пользователя через корпоративные
DNS и VPN-маршруты. Версия `0.2.3` поддерживает проверку подключения, публикацию
комментариев и загрузку вложений.

## Запуск

1. Установите Node.js 18 или новее.
2. Подключите корпоративный VPN.
3. Запустите `start.command` на macOS, `start.cmd` на Windows или `start.sh` на Linux.
4. Введите адрес QA Report и 8-значный код из окна «Локальный агент».
5. Выберите способ Jira-авторизации. Для SSO/2FA используйте Copy as cURL из
   авторизованной вкладки Jira; credential извлекается и сохраняется только локально.
6. Оставьте окно агента открытым и отправляйте чек-лист обычной кнопкой QA Report.

Чтобы обновить Jira credential после истечения cookie:

```bash
node qa-report-agent.js --configure-jira
```

Чтобы удалить локальную привязку, выполните:

```bash
node qa-report-agent.js --reset
```

Ключ сопряжения и Jira credential хранятся только на устройстве в конфигурационном
файле с ограниченными файловыми правами. Агент не является универсальным
HTTP-прокси и выполняет только явно разрешённые Jira-команды.
