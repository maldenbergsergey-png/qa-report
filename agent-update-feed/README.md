# Подписанные обновления QA Report Agent

Этот каталог содержит только небольшие подписанные обновления кода для уже
установленного агента. Docker включает его в `/app/agent-releases`; сайт отдаёт
`latest.json` и ASAR напрямую через прежний `/agent-updates/`.

Полные установщики хранятся в GitHub Releases. Закрытый ключ подписи сюда не входит.
При обновлении сначала добавьте проверенный ASAR, затем замените `latest.json`.
Прежние ASAR сохраняйте для клиентов с ранее полученным каталогом.
